# Правила работы с этим репозиторием

Файл читает агент перед тем, как что-то менять. Он намеренно короткий: длинная инструкция
вытесняет из контекста саму задачу.

## Что это за проект

Сервис личных дедлайнов. Пользователь один. Главный сценарий: завести срок, утром увидеть
то, что горит, отметить выполненное.

## Как запустить и проверить

- установка зависимостей: `make install`
- запуск сервиса: `make run`
- проверки: `make test`

Любое изменение считается готовым только после того, как `make test` прошёл.

## Границы

- Файл `.env` не читать и не изменять, секреты в код не переносить.
- Зависимости не добавлять без явной просьбы, версии в `requirements.txt` закреплены.
- Менять за один заход один смысловой кусок, чтобы diff читался глазами.
- Ничего сверх того, что описано в `spec.md`, не добавлять.

## Структура

- `app/main.py` - маршруты сервиса
- `app/config.py` - настройки, читаются из окружения
- `tests/` - проверки, запускаются одной командой

## Чего в проекте пока нет

Базы данных, аутентификации, уведомлений и контейнеров нет намеренно: они появятся на
следующих занятиях курса. Не добавлять их по своей инициативе.
